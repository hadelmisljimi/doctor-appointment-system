# 📌 Система за записване на час при лекар – Backend (Дипломен проект)

## 📖 Описание на проекта

Системата за записване на час при лекар представлява backend приложение, разработено със Spring Boot, което позволява управление на пациенти, лекари и медицински прегледи.

Системата поддържа автентикация на потребители, ролеви достъп и пълна логика за резервация на часове.

---

## ⚙️ Използвани технологии

- Java 17+
- Spring Boot
- Spring Security (JWT Authentication)
- MongoDB
- Spring Data MongoDB
- Swagger / OpenAPI
- Maven

---

## 🧩 Архитектура на системата

Проектът е структуриран на слоеве:

- Controller слой (REST API)
- Service слой (бизнес логика)
- Repository слой (достъп до MongoDB)
- DTO слой (обмен на данни)
- Security слой (JWT + филтри)
- Global Exception Handling

---

## 👥 Роли в системата

Системата поддържа 3 роли:

- ADMIN
- DOCTOR
- PATIENT

Достъпът до ресурсите е контролиран чрез role-based authorization.

---

## 🔐 Автентикация и сигурност

- JWT базирана автентикация
- Custom JWT filter
- BCrypt криптиране на пароли
- Защитени REST endpoint-и
- Role-based access control

## 🚫 Бизнес правила и валидации

Системата включва следните проверки:

- ❌ Не може да се записва час в миналото
- ❌ Не може да се записва час за минала дата
- ❌ Не може да се записва през уикенда
- ❌ Часовете са ограничени до 30 минутни интервали
- ❌ Не може да се резервира вече зает час (collision check)
- ❌ Валидация на работно време
